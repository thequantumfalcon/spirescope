# Getting Help

- **Bug reports and feature requests** — open a
  [GitHub issue](https://github.com/thequantumfalcon/spirescope/issues/new/choose)
  using the matching template.
- **Questions and troubleshooting** — check the in-app guide (`/guide`),
  [docs/ANTIVIRUS.md](docs/ANTIVIRUS.md) for download warnings, and the
  README's Configuration section for environment variables. If that doesn't
  cover it, open an issue.
- **Security vulnerabilities** — do NOT open a public issue. Follow
  [SECURITY.md](SECURITY.md).

This is a solo-maintained project; responses can take a few days.
